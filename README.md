# Web自動販売機システム

配列データで商品管理と、ボタンの配置など現実の自動販売機を意識して作成しました。
---

## 機能一覧
- 連続投入可能：連続でお金を投入し、合計金額を自販機内にキープすることができる
- バリデーション：
  - 小数点入力のエラー検知
  - 文字列や0円以下の不正入力検出
  - 10円単位のみ入力可能
- おつり計算：投入合計金額が商品の価格に達しているかを判定し、正確なおつりを算出


## 動かし方
- セットアップ手順：以下のファイルをダウンロード
  - zihanki.js
  - style.css
  - vending.html

- 実行方法(コマンド)
  - Windowsの場合：start zihanki.html
  - Macの場合：open zihanki.html
